# Questions Workflow

Use this folder only for questions that are actually needed.

## Rule

Before adding a question here:

1. Check the source material in `/Users/filipmicevski/Desktop/ucenje/presentations`.
2. If the answer is already clearly covered in the presentation material, do not store a duplicate question here.
3. Only store questions here when they add value:
   - the question is not directly covered in the material
   - the question needs synthesis across multiple presentations
   - the question is custom and worth keeping for later practice

## Working approach

- `presentations/` = source material
- `questions/` = filtered question set only

When you send new questions or extra material, the first step is always to read the presentation material and avoid building an unnecessary question database.
