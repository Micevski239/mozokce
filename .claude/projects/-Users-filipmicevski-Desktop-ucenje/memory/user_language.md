Прашањата и одговорите треба да бидат на течен природен македонски јазик со минимум англицизми (80/20 однос).
Стандардни кратенки (NC, EC, PPC, BCC, GACC, CACC, RACC, CFG, RIPR, DU) може да останат на англиски.

**Why:** Корисникот забележа дека AI ги прави точните одговори најдолги и очигледни, а погрешните кратки и слаби.

**How to apply:** При генерирање прашања: (1) балансирај ги должините на понудените одговори, (2) направи ги дистракторите подеднакво убедливи и тематски релевантни, (3) користи македонски за сите описни зборови (test requirement → тест-барање, coverage → покриеност, node → јазол, edge → ребро, path → патека, fault → недостаток, failure → испад, developer → програмер, source code → изворен код, statement → наредба, branch → гранка, feasible → остварлив, subsume → опфаќа, reachable → достижен).
